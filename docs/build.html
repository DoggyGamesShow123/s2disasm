  • BPS is a modern, checksummed patch format (Beat Patching System) designed by byuu/Near. It encodes differences using actions like SourceRead, TargetRead, SourceCopy, and TargetCopy, with variable‑length integers and final checksums. [1](https://floating.muncher.se/byuu/bps/bps_spec.html)[2](https://github.com/blakesmith/rombp/blob/master/docs/bps_spec.md)
    • 
      
  • IPS is the classic patch format (International Patching System) with simple records and optional RLE records (no built‑in checksum), widely used for older hacks. [4](https://zerosoft.zophar.net/ips.php)[5](https://sneslab.net/wiki/IPS_file_format)
    • 
      
  • Distributing patches is the recommended way to share ROM modifications (patch = differences; it does not include the game). [6](https://rompatcher.app/patch-formats/)
