What is this?
  • Emulator UI is loaded from an external WebRetro instance.
  • Default core: genesis_plus_gx. You can change the ROM with ?rom= in the URL.
  • Example: ?rom=./roms/s2built.bin (auto-resolves to an absolute URL)

Build notes

  • Windows: run build.bat
  • macOS/Linux: run build.lua using Lua 5.3 (older Lua versions will error on //, <<, >>)
  • Output: s2built.bin

These requirements come from the upstream Sonic 2 disassembly readme.
