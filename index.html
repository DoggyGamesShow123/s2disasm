Build instructions

  • Windows: run build.bat
  • macOS/Linux: run build.lua with Lua 5.3
  • Output: s2built.bin
  • Note: Lua 5.3 is required (older versions will error on //, <<, >>)

Reference: upstream sonicretro/s2disasm README.
